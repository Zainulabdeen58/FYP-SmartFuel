Zaroori

User ko seedha nuqsan

Z-1

Database ki chhoti si kharabi par har user logout ho jata hai

Open
backend/middleware/auth.js:25 aur frontend/src/api.js:30
Masla
protect middleware har error ko 401 "Invalid or expired token" bana deta hai, chahe asal wajah database ka error ho. Phase 0 ka naya frontend code har 401 par user ko logout kar deta hai.
Kab hota hai
MongoDB connection ek pal ke liye toota, User.findById fail hua, server ne 401 bheja, aur sab signed-in users login page par pahunch gaye.
Hal
protect mein sirf token wale errors (JsonWebTokenError, TokenExpiredError) par 401 dein. Baqi errors next(err) se error handler ko bhejein, jo 500 dega aur user logout nahi hoga.
Z-2

Purani duplicate plate wali gaariyan ab edit nahi hotin

Open
backend/controllers/vehicleController.js:72
Masla
Update par duplicate check har dafa chalta hai jab request mein registration number ho, chahe number badla hi na ho. Edit form hamesha registration number bhejta hai.
Kab hota hai
Phase 0 se pehle do gaariyan "ABC123" ke saath ban chuki hain. Ek ka sirf naam badlein to "already exists" (409) aata hai. Dono gaariyan edit hi nahi ho saktin.
Hal
Check sirf tab chalayein jab naya number (trim aur uppercase karke) gaari ke maujooda number se mukhtalif ho.
Z-3

Number ki shakal mein plate bhejne se duplicate check bach jata hai

Open
backend/controllers/vehicleController.js:25
Masla
registrationTaken sirf text (string) check karta hai. Number aaye to "pehle se nahi hai" maan leta hai, phir Mongoose usay text bana kar save kar deta hai.
Kab hota hai
"1234" pehle se maujood hai. API se registrationNumber: 1234 (number) bheja, to doosri "1234" gaari ban gayi.
Hal
Check se pehle value ko String() mein badlein, ya jo text na ho usay 400 error se rok dein.

D-1

Admin edit mein organizationName: null par 500 error

Open
backend/controllers/adminController.js:60
Masla
Validation null par user ka purana naam check kar leti hai aur pass ho jati hai. Lekin save karte waqt null.trim() crash ho jata hai.
Kab hota hai

Open
frontend/src/components/Admin.jsx:84

Kab hota hai

D-3

Open
backend/middleware/errorHandler.js:32
Masla

D-6

Ek hi waqt do requests se duplicate plate ban sakti hai

Open
backend/controllers/vehicleController.js:24
Masla
Pehle "hai ya nahi" check hota hai, phir save. Beech mein doosri request aa jaye to dono check pass kar jati hain.
Kab hota hai
Do users ek hi second mein same plate save karein, to do gaariyan ek hi number ke saath ban jati hain. Mumkin hai magar kam hota hai.
Hal

D-7

Open
